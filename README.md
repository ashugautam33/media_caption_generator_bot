# 📸 Media Caption Generator Bot

Telegram bot that generates AI-powered captions for photos and videos.

## Features

- Photo captions
- Video captions
- Instagram captions
- Short captions
- Funny captions
- Professional captions
- Travel captions
- Romantic captions
- Viral captions
- Aesthetic captions
- Attitude captions
- Bollywood captions
- Custom styles

## Languages

- English
- Hindi
- Hinglish
- Punjabi

## Technology

- Python
- Telegram Bot API
- OpenAI API
- FFmpeg
- Docker
- Railway

## Environment Variables

The bot requires:

BOT_TOKEN

OPENAI_API_KEY

OPENAI_MODEL

Never upload the real API keys to GitHub.

## Run

Install dependencies:

pip install -r requirements.txt

Then create a `.env` file:

BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
OPENAI_API_KEY=YOUR_OPENAI_API_KEY
OPENAI_MODEL=gpt-5.6

Run:

python bot.py
