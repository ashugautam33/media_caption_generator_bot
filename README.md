# 📸 Media Caption Generator Bot

A Telegram bot that uses AI to generate captions for photos and videos.

## ✨ Features

- 📸 Photo caption generation
- 🎥 Video caption generation
- 🔍 AI visual analysis
- 📸 Instagram captions
- ⚡ Short captions
- 😂 Funny captions
- 💼 Professional captions
- ✈️ Travel captions
- ❤️ Romantic captions
- 🔥 Viral captions
- ✨ Aesthetic captions
- 😎 Attitude captions
- 🎬 Bollywood captions
- 🎨 Custom caption styles

## 🌐 Languages

- 🇬🇧 English
- 🇮🇳 Hindi
- 🗣 Hinglish
- 🅿️ Punjabi

## 🔄 Additional features

- Regenerate caption
- Change caption style
- Change language
- Upload new media
- Generate hashtags
- Generate short alternative
